# Third-party UI assets

These assets are bundled so the demonstration UI works without a runtime CDN connection. Their original license banners are retained where present. Python dependencies have their own licenses in the installed distributions.

| Asset | Version / source | License / copyright |
|---|---|---|
| Bootstrap CSS | 5.3.8, https://github.com/twbs/bootstrap | MIT, The Bootstrap Authors |
| Chart.js UMD | 4.5.1, https://github.com/chartjs/Chart.js | MIT, Chart.js Contributors |
| Bootstrap Icons hospital SVG | 1.13.1, https://github.com/twbs/icons | MIT, The Bootstrap Authors |

Pinned distribution URLs: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css`, `https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js`, `https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.1/icons/hospital.svg`.

Full license texts are included in `static/vendor/LICENSE-bootstrap.txt`, `LICENSE-chartjs.txt`, and `LICENSE-bootstrap-icons.txt`.

The MediBed mark, hospital illustration, page layout and other small SVG interface glyphs are project-authored code assets.
